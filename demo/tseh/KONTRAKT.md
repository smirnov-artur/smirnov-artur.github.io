# ЦЕХ — контракт станции

Витрина — один непрерывный тёмный цех, камера едет по рельсу, у каждого кейса —
работающая станция. Твоя задача — ОДНА станция: живая физика в миниатюре,
кинематографичная, как кадр из фильма. Не дашборд, не прибор — вещь, на которую
смотрят. Эталон планки — site/cases/aurum (бронза, свет) и site/cases/ferro.

## Файл

`site/tseh/stations/<имя>.js` — ES-модуль, default export:

```js
export default {
  name: 'forge',                 // слаг = каталог кейса
  title: 'Свободная ковка',      // подпись в лейбле
  line:  'смета поковки: удары, нагревы, цена партии', // одна строка, что считает кейс
  accent: 0xff6a1c,              // ЕДИНСТВЕННЫЙ насыщенный цвет станции
  async build(T, TSL, ctx) {
    // строишь group, НЕ добавляя в сцену — добавит зал
    return {
      group,                        // T.Group, основание на y=0, вписан в цилиндр r≤1.6м, h≤2.2м
      update(t, dt, focus, ptr) {}, // каждый кадр; focus 0..1 — близость камеры
      dispose() {}                  // освободить RT/геометрию
    };
  }
}
```

`ctx`: `{ renderer, quality: 'hi'|'soft', envNode, assetsBase: '../assets/' }`.
`ptr`: `{ ndc: {x,y}, world: T.Vector3|null (пересечение с плоскостью y=0 в локале станции), down: bool, hit: bool }`.

## Железные правила (нарушение = переделка)

1. **Свой рендерер, своя сцена, свой композер, свой тонмаппинг — ЗАПРЕЩЕНЫ.**
   Пост (bloom, зерно, грейд) делает зал. Твоё свечение — эмиссия материала.
2. **Масштаб — метры.** Основание y=0, центр в (0,0,0). Стол/постамент НЕ строить —
   у зала свой; строишь только предмет и его оснастку.
3. **Палитра:** все материалы нейтральные тёмные (сталь, чугун, стекло, камень),
   насыщенный цвет — ТОЛЬКО accent и только через эмиссию/свечение процесса.
   Никаких своих цветных ламп. Локальный свет ≤1 PointLight, и только если он
   физически обоснован (раскалённый металл греет наковальню).
4. **Бюджет:** ≤60k треугольников, ≤2 своих RenderTarget ≤256², ≤1 compute-прохода
   на кадр при focus<0.5. При focus→0 сим замирает в «дыхание» (почти даром).
5. **Физика настоящая и живая.** Ядро сима бери из site/cases/<имя>/index.html —
   там оно уже написано и проверено; урежь разрешение, не механику.
   Заранее записанных анимаций (AnimationClip по таймлайну) нет.
6. **Ответ на касание обязателен.** При focus>0.5 станция отвечает на ptr
   физикой процесса (удар молота в точку, иней от пальца, разряд к точке).
   Отклик ≤100мс, читаемый.
7. **TSL:** материалы — узловые (NodeMaterial семейство из three-2026.js),
   `onBeforeCompile` НЕ существует в этой сборке. Compute — через TSL
   (`Fn().compute()`, StorageTexture) или ping-pong RenderTarget.
8. **Никаких fetch за пределы site/assets/ и своего каталога кейса.**
   HDRI не грузить — окружение даёт зал через ctx.envNode.

## Самопроверка (обязательна, в отчёт — числа)

Харнесс: `site/tseh/index.html?solo=<имя>` — зал подставит твой модуль на
пьедестал с настоящим светом и постом. Сервер: `python -m http.server <порт>`
из корня konvjob, порт назначен в брифе.

1. Скриншот 1440×900 при focus=1 — глазами: силуэт читается за секунду,
   заполнение центральной трети кадра, ничего не выбито в белое.
2. Консоль: 0 ошибок.
3. Треугольники: `renderer.info.render.triangles` в кадре ≤ 60k сверх зала.
4. Отклик на клик виден на паре скриншотов до/после.

Вернуть куратору: путь модуля, 4 числа (треугольники, RT, время build мс,
строк кода), путь скриншотов, 5 строк — что за физика и что делает касание.
Сырой код и логи не возвращать.
