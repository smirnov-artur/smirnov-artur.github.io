Авито не подключён
  1. Пришлите прайсФайл Excel или csv, можно ссылку на Google Sheets. По нему ИИ‑продавец отвечает покупателям: что есть, почём, чем заменить.
  2. Подключите АвитоОткроется Авито: войдите под своим аккаунтом и нажмите «Разрешить». Ключи не нужны, пароль нам не передаётся. Когда кабинет подключится, в чат Telegram придёт сообщение.Нужны ключи API из Авито Pro. Это минут пять, шаги ниже.
    У меня уже есть свои ключи API
    1. Откройте Авито ProНа компьютере: pro.avito.ru.
    2. Профиль и настройки → Интеграции и APIСлева внизу.
    3. Создать ключИли «Получить доступ к API». Название любое, например «ИИ‑продавец».
    4. Скопируйте client_id и client_secretЦеликом, обе строки.
    5. Пришлите их в чат TelegramОдним сообщением после команды /avito. Сообщение с ключами ИИ‑продавец сразу удалит.

    Ключи дают доступ только к API: пароль от кабинета не нужен, отозвать их можно там же в любой момент.

    Нет подписки с API?

    API чатов открыт не на всех подписках Авито: в Товарах и Работе нужен «Максимальный», в Услугах — «Расширенный» или «Максимальный». Без такой подписки Авито не пустит ни по кнопке, ни по ключам.

    Это не тупик: подключите личный Telegram. Там подписка Авито не нужна, прайс тот же. Нужен Telegram Premium.

  3. ИИ‑продавец отвечаетПокупателям в Авито, по вашему прайсу. Копию каждого ответа присылает в чат Telegram. Скидки, опт, возвраты и жалобы оставляет вам.
